## What Is This?

This site is a living demonstration of AI's capabilities on three levels:

1. **AI as Predictor** — A curated timeline of predictions about the future of AI, spanning 2023 to 2035, generated by AI models.

2. **AI as Validator** — As real-world dates pass, predictions are automatically marked **accurate** or **inaccurate** based on what actually happened.

3. **AI as Designer** — Every 24 hours, **GitHub Copilot** autonomously evolves the visual design of this site by predicting what future UI/UX aesthetics will look like. It commits those changes directly to the repository.

## Setup

### Prerequisites
- Node.js 20+
- A [Cloudflare Pages](https://pages.cloudflare.com) project connected to this repository
- GitHub Models access (available on GitHub Free/Pro)

### Local Development

```bash
npm install
npm run dev
```

### Deploy to Cloudflare Pages

1. Fork/clone this repository
2. In the [Cloudflare Dashboard](https://dash.cloudflare.com), create a new Pages project and connect it to your repo
3. Set the build command to `npm run build` and output directory to `dist`
4. Cloudflare Pages automatically redeploys on every push to `main`
5. The `daily-evolution.yml` GitHub Action runs at 12:00 UTC daily, commits the evolved theme, and triggers a Cloudflare redeploy

### Adding Predictions

Edit `src/data/predictions.json`. Each prediction follows this schema:

```jsonc
{
  "id": "pred-YYYY-##",
  "date": "YYYY-MM-DD",           // When the prediction was made
  "validationDate": "YYYY-MM-DD", // When it should be validated
  "category": "Category Name",
  "confidence": 75,               // AI's confidence 0-100
  "prediction": "The prediction text...",
  "outcome": null,                // null = pending, string = resolved
  "status": "pending",            // "accurate" | "inaccurate" | "pending"
  "tags": ["Tag1", "Tag2"]
}
```

### Validating Predictions

When a `validationDate` passes, update the prediction in `predictions.json`:
- Set `status` to `"accurate"` or `"inaccurate"`
- Set `outcome` to a description of what actually happened
- Commit — the site will update automatically
